# shkaf-hud

Домашний дашборд для Unraid-сервера: Arduino Pro Micro с WS2812-лентой (диодная матрица) 
и OLED-экраном показывает загрузку CPU/RAM/сети/дисков в реальном времени, статистику 
библиотеки Plex, активные стримы и загрузки qBittorrent.

Управляется Docker-контейнером, который собирает метрики хоста, рендерит строки для экрана 
и шлёт на плату только изменения. Включает PWA-вебинтерфейс для управления экранами и цветами.

## Что показывает

### Лента (WS2812)
4 вертикальных бара по 8 диодов:
- **CPU** (по умолчанию красный)
- **RAM** (зелёный)
- **NET** (синий)
- **DISK** (жёлтый)

Цвет каждого бара настраивается в веб-интерфейсе. При 100% бар становится красным.

### OLED (128x64, SSD1306, I2C)
Пользовательские экраны, чередующиеся в ротации. Каждый экран состоит из 3 строк (L1, L2, L3).
- **Гибкие шаблоны:** Текст + переменные (например, `"Playing {stream_pos}/{stream_count}"`).
- **Автоскрытие:** Если данных нет (нет стримов, торрентов или интерфейс DOWN) — экран молча пропускается.
- **Плавный скроллинг:** Длинные строки (названия фильмов, IP+интерфейс) скроллятся по пикселям.
- **Независимый таймер:** Время показа настраивается для каждого экрана отдельно.

### Веб-интерфейс (`http://<IP>:8189`)
- **PWA:** Можно установить на телефон как приложение.
- **Редактор экранов:** Drag-and-drop сортировка, форма L1/L2/L3, живое превью.
- **Легенда переменных:** Клик по переменной вставляет её в шаблон.
- **Настройка баров:** Цветовые пикеры и яркость.

## Железо
- Arduino Pro Micro (32u4 / Leonardo-совместимая)
- WS2812 LED-матрицы (в оригинальной сборке — 2 шт 4x4, физически 4 бара по 8 диодов)
- OLED SSD1306 128x64, I2C

## Установка на Unraid (через GUI)
1. **Docker → Add Container**
2. В поле Template вставить: 
   `https://raw.githubusercontent.com/RGCustom/shkaf-hud/main/unraid-template/shkaf-hud.xml`
3. Заполнить свои значения (Tautulli, qBittorrent, пути) → **Apply**.
