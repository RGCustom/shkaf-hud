# shkaf-hud

Домашний дашборд для Unraid-сервера: Arduino Pro Micro с WS2812-лентой (диодная матрица)
и OLED-экраном показывает загрузку CPU/RAM/сети/дисков в реальном времени, а также
статистику библиотеки Plex и что сейчас смотрят (через Tautulli).

Управляется контейнером `shkaf-hud`, который собирает статистику хоста, шлёт её по
USB-serial на плату, и отдаёт лёгкий веб-интерфейс с живым превью и настройкой цветов.

## Что показывает

**Лента (WS2812)** — 4 бара по 8 диодов:
- CPU (по умолчанию красный)
- RAM (зелёный)
- NET (синий)
- DISK, `%util` (жёлтый)

Цвет каждого бара настраивается в веб-интерфейсе контейнера и сохраняется между
перезапусками. При достижении 100% бар становится красным независимо от выбранного цвета.

**OLED (128x64, SSD1306, I2C)** — два экрана, чередуются автоматически:
- Библиотека: количество фильмов/сериалов + занято/свободно места на массиве (TB, с точностью
  до сотых), пока нет активных стримов - статичный экран
- Текущий стрим: название (бегущей строкой, если не влезает), пользователь, прогресс - по
  одному экрану на каждый активный поток, с ротацией

**Веб-интерфейс** (`http://<IP>:8189`) — живое превью того, что происходит на ленте/экране,
плюс цветовые пикеры для каждого бара. Показывает предупреждение, если плата отключена;
статистика при этом продолжает собираться.

## Железо

- Arduino Pro Micro (32u4 / Leonardo-совместимая)
- WS2812 LED-матрицы (в оригинальной сборке - 2 шт 4x4, физически расположены как 4
  вертикальных бара по 8 диодов)
- OLED SSD1306 128x64, I2C

## Установка на Unraid (через GUI, образ из ghcr.io)

1. **Docker** → **Add Container**
2. В поле **Template** вставить:
   ```
   https://raw.githubusercontent.com/RGCustom/shkaf-hud/main/unraid-template/shkaf-hud.xml
   ```
3. Форма подтянется автоматически - заполнить свои значения (Tautulli URL/ключ, путь к
   Pro Micro и т.д.) → **Apply**

Подробности по каждому полю - см. таблицу переменных ниже.

### Обновление контейнера

```bash
docker pull ghcr.io/rgcustom/shkaf-hud:latest
docker stop shkaf-hud && docker rm shkaf-hud
```
и заново **Add Container** → **Template** → `shkaf-hud` (подхватит сохранённый персональный
конфиг). Либо включить автообновление через плагин **Community Applications** → **Auto Update
Applications**.

Версия реально запущенного кода видна в первой строке `docker logs shkaf-hud`.

## Установка через docker-compose (вне Unraid)

```bash
cp .env.example .env
# заполнить .env своими значениями
docker compose up -d --build
```

## Переменные конфигурации

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SERIAL_PORT` | `/dev/ttyACM0` | Путь к USB-устройству Pro Micro внутри контейнера |
| `BAUD` | `115200` | Скорость serial, должна совпадать со скетчем |
| `TAUTULLI_URL` | `http://127.0.0.1:8181` | Адрес Tautulli |
| `TAUTULLI_API_KEY` | - | Settings → Web Interface → API в Tautulli |
| `NET_IFACE` | `br0` | Интерфейс для измерения сетевой нагрузки |
| `NET_MAX_MBPS` | `300` | Что считать 100% на шкале сети |
| `DISK_DEVICES` | пусто (автоопределение) | Список дисков через запятую для %util, напр. `sdb,sdc` |
| `ARRAY_PATH` | `/mnt/user` | Точка монтирования массива для подсчёта занятого/свободного места |
| `ARRAY_REFRESH_SECONDS` | `60` | Как часто пересчитывать место на массиве |
| `LIBRARY_REFRESH_SECONDS` | `300` | Как часто обновлять счётчики Movies/Series |
| `SCREEN_ROTATE_SECONDS` | `4` | Через сколько секунд OLED переключает экран |
| `POLL_INTERVAL` | `1.0` | Как часто слать данные на Pro Micro |
| `WEB_PORT` | `8189` | Порт веб-интерфейса |
| `CONFIG_DIR` | `/config` | Куда сохраняются выбранные цвета лент |

Сеть контейнера - `host` (нужно для честного чтения `/proc/net/dev` хоста и доступа к
сервисам вроде Tautulli независимо от того, в какой docker-сети они сами находятся).

## Протокол Pro Micro <-> хост

Одна строка в секунду по serial, pipe-delimited:

```
CPU:57|RAM:42|NET:78|DISK:61|C0:FF0000|C1:00FF00|C2:0000FF|C3:FFFF00|SCREEN:LIB|MOVIES:1243|SERIES:87|TOTC:941|FREEC:310|ARRPCT:67
```
или, пока идёт воспроизведение:
```
CPU:57|RAM:42|NET:78|DISK:61|C0:...|SCREEN:STREAM|IDX:1|CNT:2|TITLE:...|USER:...|PROG:45
```

`C0..C3` - цвета баров в hex (настраиваются в веб-интерфейсе). `TOTC`/`FREEC` - объём массива
в "центи-терабайтах" (TB × 100, целое число - Arduino парсит только целые значения, делит на
100 при выводе).

## Калибровка ленты

Порядок физического подключения матриц в цепочку неизвестен заранее - в скетче есть
режим калибровки: пришли `CAL` в Serial Monitor, диоды по одному загорятся белым с выводом
номера в консоль, дальше нужно вручную заполнить массив `LED_MAP` в `.ino` под свою раскладку.
